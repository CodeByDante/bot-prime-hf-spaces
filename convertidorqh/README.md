# 🚀 Convertidor QH

Esta es una versión optimizada y simplificada del bot, enfocada exclusivamente en la herramienta **Convertidor QH (Quality & High-performance)**.

## 🛠 Funciones Principales
- **Descarga Turbo (x32)**: Utiliza 32 conexiones simultáneas para descargar medios de Telegram a máxima velocidad.
- **Optimización de Video**: Extrae automáticamente metadatos (Ancho, Alto, Duración) y genera miniaturas para un reenvío estético.
- **Procesamiento de Imágenes**: Descarga y reenvío rápido de fotos.
- **Limpieza Automática**: Borra los archivos procesados del servidor inmediatamente después de enviarlos para ahorrar espacio.

## 🚀 Cómo Iniciar
1.  Ejecuta `start.bat` para instalar las dependencias necesarias.
2.  Ejecuta `run.bat` para iniciar el bot.

## ❓ Comandos del Bot
- `/start`: Bienvenida e introducción.
- `/help`: Explicación detallada del funcionamiento técnico.
